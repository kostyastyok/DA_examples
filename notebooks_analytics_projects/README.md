# Ноутбуки и аналитические проекты

В этом разделе будут собираться отдельные исследовательские ноутбуки, прототипы и мини-проекты, посвящённые анализу данных.

## Структура
- `exploratory/` — быстрые эксперименты и анализы.
- `research/` — более структурированные проекты с подробными выводами.

При необходимости создавайте дополнительные подпапки и дополняйте этот файл описанием проекта.
