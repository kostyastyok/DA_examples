# DA_examples

В этом репозитории представлены учебные проекты с курсов "Аналитик данных" от Яндекс.Практикума и "Симулятор аналитика" от Karpov.Cources,
а так же примеры задач/упражнений и различных тем, изучением которых я занят в настоящее время.

## Раздел для ноутбуков и аналитических проектов

В каталоге [`notebooks_analytics_projects/`](./notebooks_analytics_projects) собираются исследовательские ноутбуки, прототипы и мини-проекты по анализу данных.
Внутри доступны подпапки для быстрых экспериментов (`exploratory/`) и более структурированных исследований (`research/`).
